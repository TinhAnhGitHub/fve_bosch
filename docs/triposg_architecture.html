THE IDEA

Two learned parts, with different jobs.

The shape model predicts geometry in arbitrary units. The size head predicts one physical RMS radius from the photo. A single photo cannot uniquely reveal hidden geometry or absolute scale: these are learned predictions, guided by the training distribution.

Shared frozen encoders

DINOv2 converts pixels to image tokens. The VAE converts ground-truth surfaces to latent tokens. Cache these outputs once; neither encoder occupies the training GPU.

Phase 1 · Shape

Train attention LoRA adapters, or all transformer weights, to predict latent flow velocity using the image as conditioning. The frozen VAE is the geometry vocabulary.

Phase 2 · Size

Train a small MLP on cached image features and metric radius labels. It does not load or run the shape generator. The two phases can run in either order.

00 / BEFORE BOTH TRAINING PHASES

Prepare paired photos and meshes.

Split by physical object before encoding. The manifest keeps exact duplicate meshes together and accepts manually supplied object groups. Features and mesh posteriors are cached per object; the physical label is measured before normalizing geometry.

Why 257 × 1,024?

DINOv2-Large receives a 224 × 224 crop and uses 14 × 14 pixel patches. This creates 16 × 16 = 256 patch tokens. Add one CLS token: 257 tokens, each with 1,024 channels. These are learned visual descriptors, not XYZ coordinates.

Two different normalizations

VAE input: center the surface, optionally use a proper PCA rotation, then scale the largest absolute mesh coordinate to 0.95. Final output: center the sampled cloud and normalize its RMS radius to one. Keeping VAE coordinates within its decoder domain matters.

01 / SHAPE TRAINING

Teach velocity in latent space.

The target mesh is compressed into clean latent z. Mix it with independent Gaussian noise ε at a sampled noise fraction σ. The transformer receives the mixture, timestep, and image features. It predicts a tensor of the same shape as the latent.

What is a noisy latent?

Each latent token has 64 learned channels. Noise perturbs those channels; it is not noise added to mesh vertices. σ = 1 is all noise; σ = 0 is the clean latent.

Blue = clean contribution · purple = noise contribution. This illustrates interpolation weights, not signal-to-noise energy.

Match the released scheduler's signs.

xσ = (1 − σ)z + σε
tmodel = 1000σ
vtarget = z − ε
Lflow = mean((v̂ − vtarget)²)

The solver advances toward a smaller noise fraction using x_next = x + (σ − σ_next)v̂. Its step multiplier is positive, so the target is z − ε. An inverse clean-fraction time convention needs different labels; do not interchange them.

What happens inside the transformer?

Project 64 latent channels to width 2,048, embed the timestep and prepend a time token, then pass through 21 transformer blocks. Self-attention relates shape tokens; cross-attention reads the 1,024-channel image tokens. Feed-forward layers transform token features. The output returns to B × 2048 × 64 velocity channels.

LoRA · change a low-rank branch

y = Wx + (α/r)BAx

Freeze original W. Train low-rank A and B on attention Q, K, V, and output projections in self- and cross-attention. Rank 16 and α = 16 are the initial 24 GB recipe. Gradients still pass through frozen operations to reach the adapters.

Full · change all transformer weights

Train projections, time embeddings, attention, MLPs, normalization, and skip projections. No LoRA is installed. Keep fp32 master parameters with bf16 mixed precision. DINOv2 and the VAE remain frozen. The 80 GB preset is a target, not a measured memory guarantee.

02 / SIZE TRAINING

Learn millimetres from visual features.

Concatenate the CLS token and mean patch token, then predict log RMS radius. The mesh provides the metric label only during training. The head receives no generated shape, category ID, or ground-truth volume.

The implemented head

[CLS ; mean(patches)] → 2048
LayerNorm → Linear(2048,256)
→ GELU → Dropout(0.1)
→ Linear(256,1) → log r̂

Initialize the output to the mean training log radius. Exponentiation ensures a positive radius at inference. Frozen features can be shared with shape training.

Keep the head; compare its objective.

The default uses log-radius MSE, emphasizing relative errors. A second config minimizes physical-radius MSE divided by a fixed 40² unit factor. This preserves the radius-MSE optimum while rescaling gradients. Compare final metric Chamfer and errors by size range. Neither recipe has been trained yet.

A larger head cannot resolve absolute scale when the photo contains no scale cues. Spatial pooling and ambiguous size distributions are future experiments, rather than demonstrated failures.

03 / INFERENCE

Generate shape, predict radius, multiply.

A new photo is the only observed input. The shape branch starts with independent random latent noise. Repeated transformer and scheduler steps produce a clean shape latent. The size branch predicts physical radius directly from the photo's features.

Pmm = exp(size_head(F)) × (P − mean(P)) / RMSRadius(P)

Decoding is a geometry query.

The frozen VAE takes the final latent and queried XYZ positions. It predicts one signed distance per position. Extract the zero-level surface, sample 8,192 points by triangle area, then normalize their RMS radius. Mesh vertex count is variable; final point count is fixed.

One solver step

Feed current latent + 1000σ + image features into the transformer. Combine conditional and zero-image predictions with guidance scale 7, update the latent, and repeat at the next sigma. Classifier-free guidance doubles the internal transformer batch to two; it does not double the output object count.

IMPLEMENTATION / OWNERSHIP

Lightning owns the training loop.

FoodAdaptation computes model-specific losses. Lightning handles backward passes, mixed precision, accumulation, clipping, optimizer and scheduler steps, logging, and checkpoint resume. There is no handwritten optimization loop.

Artifacts and reproducibility

metadata.json pins the source, checkpoint revision, preprocessing, groups, and tensor contract. Resume rejects a changed config, cache hash, or phase. Fixed validation noise reduces random changes between checkpoints.

best.ckpt / last.ckpt preserve training state and include frozen base weights. Exported best.pt is for inference: adapter weights in LoRA mode, transformer weights in full mode, or size MLP weights in size mode.

Checkpoint selection: minimum validation flow MSE for shape; the chosen radius objective for size. Decoded geometry is evaluated separately. A lower latent loss is not proof of lower Chamfer.

GOTCHAS / NEXT EVIDENCE

Validate the geometry before a long run.

  1. Check units and VAE reconstruction. Inspect metric meshes and frozen VAE round trips. The reduced surface sample count and PCA pose are adaptation choices, not the authors' validated fine-tuning recipe.
  2. Keep comparisons controlled. Frozen TripoSG + the same learned size head is the baseline. Compare LoRA next, then full tuning on identical holdout IDs, solver settings, masks and seeds.
  3. Separate shape error from size error. Report metric Chamfer, oracle-radius Chamfer, radius errors and generation failures. The local evaluator is not certified against the official grader.
  4. Test capacity after establishing a baseline. Attention-plus-MLP LoRA, DoRA, conditioning adapters, noise-level diagnostics and decoder geometry supervision are proposed in the README. They are not implemented experiments with measured gains.

The real pretrained model has not been trained here. Tiny CPU tests validate mathematical and API contracts, not VRAM, convergence, data quality or challenge performance. Follow the repository's cloud training policy; these scripts do not upload data.
